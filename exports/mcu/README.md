# 单片机课程讲解视频

每部视频 24 分钟，1920×1080、24 fps，普通话合成配音，画面内嵌字幕。适合按顺序学习，也可在支持 MP4 章节的播放器中跳到指定知识点。

| 视频 | 下载文件 | 对应原课件 |
|---|---|---:|
| 第一章《绪论》 | [ch01-introduction.mp4](ch01-introduction.mp4) | 63 页 |
| 第二章《单片机系统结构》 | [ch02-mcu-architecture.mp4](ch02-mcu-architecture.mp4) | 34 页 |

GitHub 页面若没有直接播放预览，可使用文件页的下载按钮，将 MP4 保存后用系统播放器打开。每部包含 28 个导航章节；部分播放器可能不展示章节菜单，但正常播放不受影响。

画面右上角保留原 PDF 页码。各页知识点按教学逻辑合并讲解，历史资料和重复内容适当概括；计算、寄存器、引脚和存储器分区用放大的表格和重绘图示解释。遇到练习可暂停演算后再核对。
