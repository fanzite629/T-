# 两章统一画面与讲解规范

## 教学基调与布局

采用清晰的工程课堂风格，主画布1920×1080、16:9。暖白背景`#F7F9FC`，深蓝灰正文`#172B4D`，蓝色`#1D4ED8`表示当前步骤，绿色`#13735B`表示已验证结果，橙色`#B45309`表示边界条件或易错提示。颜色始终配合文字、线型或符号，不单靠红绿区分正确与错误。

标题建议56—64px；关键数字与结果56—80px；正文、公式与代码36—44px；图中必要标注至少30px。源页脚注可24px，不承担主要教学内容。字体优先微软雅黑或思源黑体，位串/地址/代码使用清楚的等宽字形。汉字、英文和数学符号需确认字体覆盖，尤其是负号、乘号、上下标、低有效横线。

主要内容距离画面外边缘至少80px。结构图、时间轴和电路都以完整关系为先：全图定位一次，随后放大当前部分；放大时保留定位小图或明确的前后关联。字幕作为画面上的叠层，逐场检查是否遮住数位、引脚和箭头，必要时改变字幕位置或当前布局；不把整部视频的内容长期挤到上半屏。

## 五种可直接执行的画面模板

|模板|适用段落|构图与展示次序|验收要点|
|---|---|---|---|
|系统关系图|五大部件、三总线、测控链路|先全图，后突出当前节点；箭头随语义推进|数据/控制线型不同，箭头方向和对象完整|
|逐步演算板|进制、补码、容量、周期|题目固定上方，中间逐行推导，结果在下方；保留前一步关键值|小数点、进位、借位、位宽、单位不丢失|
|引脚与电路|DIP40、复位、P0复用|芯片轮廓与关键引脚位置稳定；电路按功能分块放大|封装视向、编号、低有效信号、芯片边界明确|
|状态对比|PSW、寄存器组、端口模式|初态→操作→终态，只有实际改变的位高亮|不把地址和内容混色，不把全部寄存器无故清零|
|独立地址空间|CODE、RAM、SFR、XDATA|分列绘图，各列独立起点，箭头带访问类型|不同空间不首尾拼接；SFR空洞与高RAM区别可见|

## 配音、字幕与节奏

- 正文按约220—250个计数字符/分钟试读。复杂公式、地址、二进制位串适当减速；表格不逐格快速念完。
- 每个讲解段落通常包含3个以上子镜头，按“建立问题—演示过程—解释结果”组织。不是让一个静态画面停留两分钟。
- 镜头切换跟随口播语义。首次定义先出现术语，再出现解释；计算时先显示待求量，随讲解依次出现中间步骤，结果最后出现。
- 数位变化采用可追踪的高亮/位移。计算已完成后保持静止，给学生观察时间；不加无意义循环闪动。
- 理解检查先给问题并保留停顿，再显示答案。稿件的额外停留时间是排稿预留，用户暂停时间不计入固定视频时长。
- 字幕建议每屏1—2行，每行约16—22个汉字，依据语义分段。中文标点保留；技术表达优先显示标准符号，如`7FH`、`T=12/fosc`，不要把口播的逐字读法直接替代画面公式。
- `B`作为二进制后缀与`B`作为字节单位必须有上下文；首次读地址时明确十六进制。`/PSEN`、`/RD`、`/WR`中的斜线是低有效标记，不作为除号朗读。
- 背景音乐可省略。若加入，仅作低音量陪衬，在计算、提问及电路解释时应避免干扰。

## 防止拥挤和遗漏

1. 屏幕核心文字是信息库，**不是要求全部同时上屏**。六行以上的表分屏，复杂公式拆步骤；先保证36px左右可读，再决定一屏放多少内容。
2. 第一章除二取余表需保留余数顺序箭头；原反补码全程固定8位；2764同时显示bit和Byte换算。
3. 第二章DIP40整图至少保留一次完整视图，细讲时分组放大；p17—18的21项SFR表按用途分屏；复位表按CPU、端口、外设分屏。
4. 第二章p28空间图必须重绘；原图中的小字和可能引起误解的标注不直接放大照搬。讲AT89S52高RAM时显示型号，结束后回到经典8051标签。
5. 画面上的附加例子标“教学示例”，不要给它伪造PDF页内来源。对原页纠错保留说明，不修改PDF本身。

## 成片时的验收

在1920×1080原尺寸和缩小到1280×720两种尺寸下检查主要文字；暂停检查小数点、上下标、正负号、所有引脚编号与地址边界。确保口播中的指示词“这里、这一位、下一步”都有对应高亮。按逐页覆盖表核对场景，再按真实音频重建字幕时间，最后检查播放头尾、声音、转场及章节导航。

当前交付包含脚本、分镜说明和静态样张；此规范中的成片验收应在实际渲染阶段执行。
