按每分钟210个汉字/字母/数字计数字符并加固定停留，两章估时分别18:44、19:29；按较慢的190计数字符分别20:35、21:25。24分钟时间表另留205秒、155秒用于图表阅读、演算和自然停连，最后各留60秒到25分钟上限的调整余量。**这些是脚本估算和制作预算，尚无配音或MP4实测时长。** 实际配音完成后重新对齐；如超时，先精简措辞和重复展示，不靠强行加速解决。

## 先看什么

1. 阅读两章的 `manuscript.md`。每段包含来源页码、逐字口播、画面执行顺序、屏幕文字、理解检查和制作备注。
2. 查看[统一画面规范](design-spec.md)与[六张画面样张](frames/README.md)。样张用于确认版式和信息层级，属于静态设计稿。
3. 按[第1章覆盖表](ch01/coverage.csv)、[第2章覆盖表](ch02/coverage.csv)检查页码。第一章导学、招聘图片、习题和末尾存储器页均已安排；第二章第29页经渲染核对为空白，明确标为复习转场。
4. 配音使用 `narration.txt`，不读制作指令。机器读取/继续编辑使用 `script.json`；24分钟版的镜头预算见各章的 `timeline.csv`，其中明确区分常速估算、较慢语速估算、固定停留和图表余量。
5. 制作前核对[技术校核说明](technical-notes.md)，尤其是经典8051与AT89S52的条件、SBUF复位、存储空间、时序、指令长度和执行周期。

## 内容重点

- **第一章：**五大部件、CPU/微机/单片机层次、三总线、系列与应用、测控链路、进制转换、二进制四则运算、原反补码、数值范围、全部课件习题、地址与容量、2764容量推导。
- **第二章：**型号与资源比较、内部结构、DIP40引脚、端口电气及复用、复位、EA/ALE/PSEN、P0取指演示、SFR、A/B/DPTR/SP、PSW、寄存器组、12T时序、存储技术与多地址空间、复位/中断入口、位寻址与高RAM。

公式、完整答案、引脚与SFR地址等制作速查资料见[第1章速查表](ch01/reference-tables.md)和[第2章速查表](ch02/reference-tables.md)。它们用于保证画面符号和数值准确，不能整表缩小后直接充当讲解画面。

## 编辑与复用

`script.json`是两章正文与分镜的单一编辑源。修改它后，在此目录运行：

```powershell
python build_manuscripts.py
```

生成器只使用Python标准库，重建逐字稿、纯配音稿、覆盖表、制作预算表与`validation.json`，并检查段落编号、页码范围、全部物理页覆盖与时长上限。按190计数字符/分钟加固定停留已超出章预算时，生成器会报错，要求精简内容。`planned_video_seconds=1440`和`max_video_seconds=1500`是本版时长约束；`reading_weight`为密集图表和演算分配更多余量。新增或改动画面样张、速查表及校核说明时，应同步人工核对。

原PDF使用SHA-256记录在[validation.json](validation.json)，方便后续发现源课件版本变化。结构覆盖检查不能替代成片验收；最终还需看清晰度、实际配音同步、字幕和知识表达。
