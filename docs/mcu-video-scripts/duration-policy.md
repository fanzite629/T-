# 一份PDF一个视频：每部不超过25分钟

本规则适用于本仓库这套单片机课程的所有PDF视频。当前已按此规则重写第一、第二章逐字稿；其他章在继续制作时沿用规则。

## 时长预算

- 完整成片最大1500秒（25:00），包含片头、片尾、转场、配音、练习停顿和静态阅读。
- 第一、第二章各以1440秒（24:00）安排28个段落；各保留60秒用于实配音后的必要调整。可以提前结束，无需用空画面凑满24分钟。
- 每章`script.json`保存预算，`timeline.csv`是制作计划，实际音频生成前不视为实测时间戳。各段连续衔接，合计恰为1440秒。
- 字数统计为汉字、拉丁字母和数字个数，不含标点。按210计数字符/分钟估算，并按190核算较慢情形。字母名称、技术缩写和停连可能增加真实发音时长，必须试听验证。
- 较慢估算之外，第一章另有205秒、第二章155秒分配给画面阅读与演算。每段`hold_seconds`是整段固定额外停留总量，不是每个子镜头的停留量。

## 内容与清晰度

保持全部物理页的对应关系。关键概念用口播解释，关键例题保留过程；背景、型号列表、同类重复练习采用合并讲解与分屏图表。完整习题答案、引脚和寄存器表仍按分镜上屏，补充速查文件便于课后核对。覆盖状态表示已进入脚本，成片还需逐场验收。

画面推进与口播同步，公式变换和信号阶段按顺序呈现。密集表格拆屏，主要文字不低于统一规范的要求；不为缩短时间把整页PDF缩成难辨的小字。练习可提示观众暂停，不在每题前加入十几秒等待。

配音超出当前场景预算时，可在本章内调整分配，优先压缩重复措辞、背景铺垫和重复展示，再重新核算。保留数位、型号前提、计算步骤和答案；不依靠整体倍速或删除末尾知识点解决超时。

## 给Claude或后续制作人的执行顺序

1. 阅读本规则、两章主稿、统一设计规范和技术校核说明；以新版`script.json`为正文来源。
2. 先完成一章正常语速配音，测量每段音频及停顿。口播与视觉同步进行，不能把整段动画时长再次加在口播后面。
3. 根据实测音频调整子镜头和字幕；优先使用每段图表余量及整章60秒调整空间，确保整部不超过1500秒。
4. 渲染后读取最终媒体时长并完整播放。配音不截断，最后一句、答案和尾画面均结束后，仍须在25:00以内。

若制作环境已有FFmpeg，可用以下命令读取实际总时长（输出单位为秒）：

```powershell
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 "chapter01.mp4"
```

验收时记录真实文件名和时长，确认数值≤1500；第一、第二章分别执行。当前仓库只有稿件、分镜、预算和静态样张，尚未产生可执行此媒体验收的成片。
