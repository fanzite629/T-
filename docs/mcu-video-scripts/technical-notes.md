# 源课件校核、适用条件与教学补充

主要依据是用户上传的两份PDF，物理页码分别为1—63与1—34。原件保持完整；文稿对易误解的表述作明确限定，不把笔误或历史背景当成现代器件的普遍事实。

## 第一章

|PDF页|处理|在稿件中的用法|
|---|---|---|
|2、5、8—11|课表、考核和招聘均为该课件的背景信息|课程安排按原课件说明；截图用于解释能力，不承诺当前薪资、岗位或课表|
|13—15|“第一台”和“所有结构没有突破”过于绝对|以1946年为课件历史起点；五大部件作为功能模型，不否定独立程序/数据空间|
|19|4004的正式商业发布节点|稿件采用1971年11月，而非把课件的1月直接称作正式发布；依据[Intel官方历史](https://timeline.intel.com/1971/the-first-programmable-microprocessor%3A-the-4004)|
|25—29|历史分期、厂家旧称、兼容体系与具体型号不能混为一谈|发展分期为教材梳理；使用“51兼容系列”；六类器件允许交叉，超8位不是自动变为16位CPU|
|30|温度范围只作为课件示例|不将民品/工业品/军品三个区间套给全部器件；实际按具体型号等级|
|43|`3AB.11H`的数值精度|精确值`939.06640625D`；课件四位小数写作`≈939.0664D`|
|53—57|“符号位+绝对值”只适用于原码理解；补码不是所有数据的唯一表示|明确字长与编码；补码最高位用负权值解释；无符号、原码、反码、补码分别讨论|
|62|Word与K的口径|16位Word限于本课件语境；本课件K=1024；区分位、字节、数量与最高地址|
|63|2764容量|A0—A12共13根地址线，D0—D7共8位：`2^13×8bit=64Kbit=8KB`|

## 第二章

|PDF页|处理|在稿件中的用法|
|---|---|---|
|2—3|系列现状和典型参数需有条件|不把“最广泛”作为当前市场结论；12MHz/1μs为经典示例|
|3、14、28|60KB/56KB是片内程序有效时的剩余映射空间|区分EA=1的片内+片外划分与EA=0全片外程序访问|
|9|P1“只能普通I/O”仅适合基本型的简化介绍|AT89S52另有P1复用；P0普通I/O与总线模式分开；输入先释放端口|
|12—13|复位不代表全部内容清零|突出PC=0000H、SP=07H、端口锁存器FFH；SBUF不假定有效；RAM需按需初始化|
|14—16|信号极性、拼写和373工作方式|使用XTAL1/XTAL2；保留低有效标记；ALE配合透明锁存器保持地址，不画成仅上升沿触发|
|17—19、33|SFR数量、PC与DPTR|经典8051公共表为21项；AT89S52有增强资源；PC为16位且不在普通SFR表，DPTR不是芯片唯一16位寄存器|
|20|P的含义、CY与OV|P由A中1的个数决定，不是十进制奇偶；用普通ADD的FFH+01H与7FH+01H作教学补充|
|23—26|周期定义及指令长度|所有12T换算均标经典条件；字节数不能推导周期数；ALE频率说明带访问/配置条件|
|28—30、33|空间、寻址方式与物理资源|程序和外部数据独立；SFR的128个地址不等于128个实际寄存器；高RAM规则仅用于支持器件|
|29|原页为空白|以复习检查转场处理，覆盖表明确标识，不虚构原页内容|
|31|AT89C51程序存储技术|按本套课件第一章p29的Flash说明统一，不照读EEPROM混称|
|31|复位及中断入口描述|列精确向量；0003H到002BH含两端为41字节，不照抄40；002BH为52的Timer2入口，不属于基本8051五个入口|

关键器件差异已与厂商原始资料核对：[Atmel AT89S52数据手册](https://www.keil.com/dd/docs/datashts/atmel/at89s52_ds.pdf)的引脚说明、SFR表、Memory Organization章节用于检查P1复用、EA映射、双数据指针和高RAM；[Philips/NXP 80C51硬件说明](https://community.nxp.com/pwmxy87654/attachments/pwmxy87654/52136tkb-board/130/1/80C51%20Family%20Hardware%20Description.pdf)的SFR、PSW及Reset部分用于检查奇偶、堆栈和复位内容。采用这些资料校正适用条件，课程正文和基本知识范围仍以用户PDF为主。

## 教学补充边界

洗手液机、风扇与温控链路；AB=30H/DB=5AH读例；5+(-4)；127+1；P0从1234H读取74H；SP压入12H/34H；两道PSW算例；MOV/MOVX/MOVC访问对比；高RAM与SFR对比，均为解释课件知识而构造的教学示例。示例数值不冒充PDF原题，指令片段也不冒充可直接烧录的完整工程。

没有对实际芯片或仿真器执行硬件测试；本次核对对象是文稿中的数学推导、地址映射、源页覆盖与画面设计。代码片段假设的型号、频率、存储内容和电路条件已在相应段落注明。
