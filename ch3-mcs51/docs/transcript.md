## [01:55–03:01] 指令的机器码：单、双、三字节（课件 P3、P4）

- `01:56` 指令存进程序存储器以后，就是一个个二进制字节。我们看课件里的三个例子。
- `02:04` 单字节指令 MOV R0,A：把累加器 A 的内容送到 R0。
- `02:10` 它的机器码是 11111000，也就是 F8H，一个字节就够了。

- `02:37` 第一个字节是操作码 88H，第二个字节是操作数地址 20H。
- `02:43` 三字节指令 MOV 60H,#2FH：把立即数 2FH 送到 60H 单元。
- `02:52` 三个字节依次是：操作码 75H，操作数地址 60H，操作数 2FH。

## [03:01–04:45] 3.1.1 汇编语言指令格式（课件 P5、P6、P7）

- `03:02` 3.1 节讲寻址方式。在此之前，先要会读汇编语句。
- `03:08` 汇编语言，就是用助记符书写的机器语言。
- `03:12` 一条语句的格式是：标号加冒号，操作码助记符，目的操作数，源操作数，最后是分号开头的注释。
- `03:24` 方括号括起来的部分可以省略。
- `03:27` 例如 STAR: MOV A,#01H，注释写的是：A 等于 01H。
- `03:35` 标号给这条语句起个名字，方便别的语句找到它，它代表这条语句所在的地址。
- `03:43` 标号由 1 到 6 个字符组成，第一个必须是字母，用冒号隔开。不是每句都要有标号，标号也不产生目标代码。
- `03:55` 操作码就是指令的助记符，说明执行什么操作。
- `04:00` 操作数说明被操作的数从哪里来、到哪里去，可以是数本身，也可以是数所在的地址。
- `04:09` 书写时要注意标点符号和数的后缀。十六进制数如果以 A 到 F 开头，前面要加 0，
- `04:18` 比如 A5H 要写成 0A5H，否则会和标号混淆。
- `04:23` 注释用分号开始，用来说明这条指令的操作，同样不产生目标代码。
- `04:31` MCS-51 一共有 7 种寻址方式：立即寻址、直接寻址、寄存器寻址、寄存器间接寻址、变址寻址、相对寻址和位寻址。

## [04:45–05:44] 指令说明中的符号约定（课件 P8）

- `04:46` 课件里描述指令时，会用到一套固定符号，先认清楚。
- `04:52` #data8、#data16，表示 8 位或 16 位的立即数；direct，表示直接地址单元；
- `05:02` SFR，表示特殊功能寄存器；Rn，表示通用寄存器 R0 到 R7；
- `05:10` @Ri，表示间接寻址寄存器，i 只能是 0 或 1；Pi，表示 P0 到 P3 四个并行 I/O 口；
- `05:19` bit，表示位操作数或位地址；addr11 和 addr16，表示 11 位或 16 位的目的地址。
- `05:28` 带一层括号的 (X)，表示 X 地址单元或寄存器中的内容。
- `05:34` 两层括号的 ((X))，表示先取出 X 的内容当作地址，再取这个地址单元里的内容。

## [05:44–06:24] 寻址方式 1：寄存器寻址（课件 P9）

- `05:45` 先强调一句：一条指令的寻址方式，指的是它的源操作数的寻址方式。
- `05:53` 第一种，寄存器寻址：对指令选定的工作寄存器 R0 到 R7 进行读写。
- `06:01` 比如 MOV A,Rn，指令里直接点名了寄存器 Rn，从 Rn 中取得源操作数。
- `06:08` 课件这里没有给具体数据，我们用一组演示数据：假设 R5 里是 3AH。
- `06:16` 执行 MOV A,R5 以后，A 变成 3AH，而 R5 的内容保持不变。

## [06:24–07:09] 寻址方式 2：直接寻址（课件 P10）

- `06:25` 第二种，直接寻址：指令里直接给出操作数所在单元的地址。
- `06:31` 格式有 MOV A,direct，也有 MOV direct1,direct2。
- `06:36` 例如 MOV A,50H：这里的 50H 不是数据，而是地址。A 得到的是 50H 单元里的内容。
- `06:45` 直接寻址可以访问三种地址空间：
- `06:49` 第一，特殊功能寄存器 SFR，直接寻址是访问 SFR 的唯一寻址方式；
- `06:56` 第二，片内 RAM 低 128 字节；第三，位地址空间。
- `07:01` 所以要记住：对特殊功能寄存器的操作，都算直接寻址。

## [07:09–08:29] 寻址方式 3：寄存器间接寻址（课件 P11、P12）

- `07:10` 第三种，寄存器间接寻址：把寄存器的内容当作地址，再到这个地址单元去读出或写入操作数。
- `07:20` 能做间接寻址的寄存器只有 R0、R1 和 DPTR 三个，书写时前面一定不能忘了 @ 号。
- `07:29` R0 或 R1，用来寻址片内或片外数据 RAM 的 256 个单元；
- `07:36` DPTR 是 16 位的数据指针，用来寻址片外数据 RAM 的 64K 个单元。
- `07:43` 来做课件上的题：R0 = 65H，65H 单元里是 47H，执行 MOV A,@R0 之后，A 等于多少？
- `07:56` 第一步，读出 R0 的内容 65H，把它当作地址；
- `08:01` 第二步，到 65H 单元取出 47H，送进 A。所以答案是 A = 47H。
- `08:07` 执行以后，R0 和 65H 单元本身都没有变。
- `08:12` 再注意区分：MOV A,@R0 访问的是片内 RAM，MOVX A,@R0 访问的是片外 RAM。
- `08:20` 两条指令的源和目的写法相同，操作的存储区不同，靠助记符来区分。

## [08:29–09:27] 寻址方式 4：立即寻址（课件 P13）

- `08:30` 第四种，立即寻址：操作数直接写在指令里，前面用井号表示立即数。
- `08:38` 比如 MOV A,#30H，执行后 A 就等于 30H。
- `08:44` 立即数可以写成十进制、十六进制，也可以写成二进制。
- `08:49` MOV A,#10000111B，A 得到二进制数 10000111，也就是 87H；
- `08:58` MOV R1,#50，这里的 50 没有后缀，是十进制，R1 得到 32H；
- `09:06` MOV R1,#0FDH，R1 得到 FDH，注意以 F 开头要补一个 0。
- `09:14` 还要记住：立即数只能作为源操作数，不能当目的操作数。
- `09:20` 课件这一页把源操作数写成了“原操作数”，是笔误。

## [09:27–11:02] 寻址方式 5：位寻址与位地址表（课件 P14、P15、P16）

- `09:27` 第五种，位寻址：对某一个二进制位进行操作。
- `09:32` 例如 MOV C,P1.1，把 P1 口第 1 位的状态送到进位标志 C。
- `09:39` 可以位寻址的，主要是片内 RAM 的位寻址区，以及地址能被 8 整除的特殊功能寄存器。
- `09:48` 位寻址区是片内 RAM 的 20H 到 2FH，共 16 个字节、128 位，位地址从 00H 到 7FH。
- `09:58` 看这张位地址表：20H 字节的 D0 到 D7，位地址是 00H 到 07H；
- `10:06` 21H 字节是 08H 到 0FH，以此类推，一直到 2FH 字节的 78H 到 7FH。
- `10:14` 表里的规律可以写成：位地址等于，字节地址减 20H，乘以 8，再加上位号。
- `10:23` 例如 24H 字节的第 1 位：24H 减 20H 得 4，乘 8 得 20H，再加 1，就是位地址 21H。
- `10:33` 所以课件说，MOV 24H.1,C 和 MOV 21H,C 的功能是一样的，都是把 C 送到这一位。
- `10:43` 注意，这里的 21H 是位地址；表里还有一个字节地址 21H，那是另一个单元，千万别混。
- `10:52` 最后，MOV 24H.1,1 这样的写法是错误的：位传送时，两个操作数中必须有一个是 C。

## [11:02–12:00] 寻址方式 6：变址间接寻址（课件 P17）

- `11:03` 第六种，变址间接寻址：把基址寄存器的内容加上变址寄存器的内容，作为有效地址去间接寻址。
- `11:13` 基址寄存器是程序计数器 PC 或数据指针 DPTR，变址寄存器是累加器 A。
- `11:22` 用到它的指令有三条：MOVC A,@A+DPTR、MOVC A,@A+PC，以及转移指令 JMP @A+DPTR。
- `11:33` 以 MOVC A,@A+DPTR 为例：DPTR 当基地址，A 的内容当偏移量，
- `11:40` 两个寄存器的内容相加得到一个地址，再把这个程序存储器单元的内容送回 A。
- `11:48` 因为 A 可以随时改变，地址就能动态变化，所以变址寻址主要用于查表。第 2 集会用它写一个查平方表的程序。

## [12:00–13:06] 寻址方式 7：相对寻址（课件 P18）

- `12:01` 第七种，相对寻址：以 PC 的当前值为基准，加上指令中给出的偏移量 rel，形成新的转移地址。
- `12:12` 课件的例子：SJMP 指令存放在 2030H 单元，rel 等于 30H。
- `12:20` SJMP 是 2 字节指令，占用 2030H 和 2031H。取完这条指令，PC 已经指向 2032H，这就是 PC 的当前值。
- `12:33` 2032H 加上 30H，等于 2062H，程序就跳到 2062H 去执行。
- `12:41` rel 是一个带符号的 8 位二进制数，最高位是符号位，必须以补码形式出现在指令中。
- `12:50` 所以转移范围是：以 PC 当前值为起点，向后最多 128 个字节，向前最多 127 个字节，也就是负 128 到正 127。

## [13:06–14:43] 寻址方式小结与指令分类（课件 P19、P20）

- `13:07` 七种寻址方式做个小结，重点记住每种方式能访问哪里。
- `13:13` 寄存器寻址：R0 到 R7，课件还列了 A、B、Cy 和 DPTR；
- `13:20` 直接寻址：片内 RAM 低 128 字节和特殊功能寄存器；
- `13:26` 寄存器间接寻址：片内 RAM 用 @R0、@R1 和 SP，片外数据 RAM 用 @R0、@R1 和 @DPTR；
- `13:38` 立即寻址：立即数就在程序存储器的指令里；变址寻址：访问程序存储器，用 @A+DPTR 和 @A+PC；
- `13:49` 相对寻址：PC 当前值加偏移量，范围负 128 到正 127；位寻址：片内 RAM 和 SFR 中可位寻址的单元。
- `14:00` 关于 B 寄存器补充一点：按指令编码，B 一般是用直接地址 F0H 来访问的，只有乘除法 MUL AB、DIV AB 里是隐含使用。
- `14:13` 最后，111 条指令按功能分成四类：
- `14:17` 数据传送指令 28 条；算术逻辑运算指令 49 条，其中算术 24 条、逻辑 25 条；
- `14:27` 控制转移指令 17 条；位操作指令 17 条。28 加 49 加 17 加 17，正好 111 条。
- `14:38` 下一集，我们从数据传送指令开始。

## [00:00–01:09] 3.3 数据传送指令：五类与操作域（课件 P21、P22、P23）

- `00:00` 这一集讲 3.3 数据传送指令，它的功能就是进行数据传送。
- `00:07` 按操作对象，可以分成五类：片内 RAM 传送指令 MOV；栈操作指令 PUSH、POP；
- `00:16` 交换指令 SWAP、XCH、XCHD；程序存储器传送指令 MOVC；片外 RAM 或 I/O 传送指令 MOVX。
- `00:28` 看课件的操作域示意图：左边是程序存储器 ROM，MOVC 把程序存储器里的数据读进来。
- `00:37` 右边是片外数据存储器 RAM，MOVX 在它和单片机内部之间传送数据。
- `00:45` 中间是特殊功能寄存器 SFR 和片内 RAM 低 128 字节，它们之间用 MOV、PUSH、POP、XCH、XCHD 和 SWAP。
- `00:57` 补充一点：图里把程序存储器标成“片外”，其实 MOVC 访问的是程序存储器，片内 ROM 和片外 EPROM 都可以。

## [01:09–03:45] 1. MOV 指令：格式与逐条执行（课件 P24、P25）

- `01:10` 先看 MOV 指令。课件特别标注：MOV 指令只影响 P 标志位。
- `01:16` 目的操作数可以是 A、Rn、direct、@Ri 和 SFR；源操作数可以是 Rn、direct、@Ri、立即数和 SFR。
- `01:28` 下面这段程序，我们一条一条执行，注意右边寄存器和 RAM 单元的变化。
- `01:36` MOV R0,#30H：立即数 30H 送 R0。MOV R1,#31H：R1 等于 31H。
- `01:46` MOV 5FH,#0AAH：立即数 AAH 送到 5FH 单元。
- `01:52` MOV 30H,#00H，30H 单元清零；MOV 31H,#01H，31H 单元放入 01H。
- `02:02` MOV A,R0：寄存器寻址，A 得到 30H。
- `02:07` MOV R1,A：R1 由 31H 变成 30H。
- `02:11` MOV A,@R0：R0 是 30H，就到 30H 单元取数，那里是 00H，所以 A 变成 00H。
- `02:22` MOV 30H,31H：把 31H 单元的 01H 送到 30H 单元，30H 单元变成 01H，31H 单元不变。
- `02:32` MOV A,5FH：A 得到 5FH 单元里的 AAH。
- `02:37` MOV 5FH,#5FH：前一个 5FH 是地址，带井号的 5FH 是立即数，执行后 5FH 单元等于 5FH。
- `02:48` MOV DPTR,#9000H：16 位立即数送数据指针，高字节 DPH 等于 90H，低字节 DPL 等于 00H。
- `03:01` MOV A,30H：30H 单元现在是 01H，所以 A 等于 01H。
- `03:08` MOV B,A：B 寄存器的地址是 F0H，执行后 B 等于 01H。
- `03:15` MOV TMOD,#11H：TMOD 是定时器方式寄存器，地址 89H，执行后 TMOD 等于 11H。
- `03:28` 再看右下角的奇偶标志 P：它始终反映 A 中 1 的个数是奇数还是偶数，A 变了，P 才可能跟着变。
- `03:37` 所以“只影响 P”，指的是 MOV 不会改动 CY、AC、OV 这些运算标志。

## [03:45–05:22] MOV 注意（1）（2）：SFR 名称与地址（课件 P25、P26）

- `03:46` 使用 MOV 指令有几点注意。
- `03:49` 第一，对 SFR 操作时，指令里常写 SFR 的名称，而不是它的直接地址，但操作和直接地址完全相同。
- `04:00` 比如 MOV B,A，就是对地址 F0H 操作；MOV TMOD,#11H，就是对地址 89H 操作。
- `04:11` 第二，80H 到 FFH 这个区间里只有 21 个 SFR，许多地址没有定义。
- `04:18` 对没有定义的地址不可操作：写进去的数据会丢失，读出来的数据是不定数。
- `04:26` 再看这两条：MOV A,#01H 和 MOV E0H,#01H。累加器 A 的地址就是 E0H，所以两条的操作结果相同，
- `04:39` 但它们不是同一条指令，目标代码不同。
- `04:44` 补充具体编码：前者是 2 字节的 74H、01H；后者是 3 字节的 75H、E0H、01H。
- `04:54` 另外按第 1 集讲的规则，以 E 开头的十六进制数要写成 0E0H，课件这里漏写了 0。
- `05:03` SFR 中可位寻址的寄存器，要求地址能被 8 整除。它们的位在指令中常以位名出现，比如 ACC.0、ACC.7、PSW.0、PSW.3、P1.1。

## [05:22–07:02] MOV 注意（3）：@Ri、# 与位传送（课件 P27、P28）

- `05:23` 第三，操作数中出现 @Ri 时，@ 的意义是：以 Ri 的内容为地址。
- `05:30` 看例子：MOV 40H,#30H，40H 单元得到 30H；
- `05:38` MOV R0,#40H，R0 得到 40H；
- `05:43` MOV A,@R0：以 R0 的内容 40H 为地址，把 40H 单元的 30H 送进 A，结果 A 等于 30H。
- `05:54` 注意：R0 里的 40H 不是被操作的数，而是被操作数所在的地址。
- `06:00` 而且 Ri 只能是 R0 或 R1，写成 @R2 到 @R7 都无效。
- `06:06` 再比较四条很像的指令：MOV A,40H，是把 40H 单元的内容送 A；
- `06:14` MOV A,#40H，是把立即数 40H 送 A；
- `06:19` MOV 40H,#40H，是把立即数 40H 送到 40H 单元存放；
- `06:26` MOV 40H,30H，是把 30H 单元的内容送到 40H 单元存放。
- `06:33` 直接地址和立即数在指令中都以数字出现，区别只在于有没有井号。
- `06:39` 传送指令运行后，源单元的内容不变。例如 MOV A,#01H 之后执行 MOV R0,A，R0 和 A 都等于 01H。
- `06:51` MOV 指令中的位传送都和 C 有关：MOV C,bit 和 MOV bit,C。bit 是位地址或位名，传送的是这一位的内容。

## [07:02–08:15] MOV 注意（4）：Rn 与工作寄存器区（课件 P29）

- `07:03` 第四，Rn 可以是 R0 到 R7 中的任何一个。
- `07:07` 片内 RAM 中有 4 个工作寄存器区，0 区到 3 区，也就是有 4 组 R0 到 R7。
- `07:16` 指令里的 Rn 属于哪一区，由程序状态字 PSW 中 RS1 和 RS0 的组合决定：
- `07:24` RS1、RS0 等于 0、0 选 0 区；0、1 选 1 区；1、0 选 2 区；1、1 选 3 区。
- `07:35` 补充各区的地址：0 区是 00H 到 07H，1 区是 08H 到 0FH，2 区是 10H 到 17H，3 区是 18H 到 1FH。
- `07:47` 计算机上电复位时，PSW 等于 00H，默认选 0 区。
- `07:54` 如果程序要用其他区，可以用位操作指令改变 RS1 或 RS0。
- `08:01` 补充一个例子：执行 SETB PSW.3，RS0 变成 1，选中 1 区，这时 R0 对应的就是片内 RAM 的 08H 单元。

## [08:15–10:14] 2. 栈操作指令 PUSH、POP（课件 P30、P31、P32）

- `08:16` 第二类，栈操作指令：压入堆栈指令 PUSH，弹出堆栈指令 POP。
- `08:23` 堆栈，是在片内 RAM 中划分出的一块特殊的连续区域，用来存放需要保存的信息。
- `08:31` 堆栈的位置由堆栈指针 SP 的内容指出。例如 MOV SP,#60H，栈的起始位置就是 60H，从 60H 开始向地址增大的方向生成。
- `08:46` 我们通过课件这段程序来理解栈操作。
- `08:50` MOV SP,#60H，建立堆栈，SP 等于 60H。
- `08:55` MOV DPTR,#8056H，DPH 等于 80H，DPL 等于 56H。
- `09:04` PUSH DPH：SP 先加 1 变成 61H，再把 DPH 的 80H 压入 61H 单元。
- `09:11` PUSH DPL：SP 再加 1 变成 62H，把 DPL 的 56H 压入 62H 单元。
- `09:18` MOV DPTR,#2000H：修改数据指针。原来的 8056H 已经安全地保存在栈里了。
- `09:29` 中间可以做其他工作。要恢复时，先 POP DPL：把 SP 指向的 62H 单元里的 56H 弹给 DPL，然后 SP 减 1 变成 61H。
- `09:42` 再 POP DPH：把 61H 单元的 80H 弹给 DPH，SP 减 1 回到 60H。DPTR 恢复成 8056H。
- `09:53` 补充：弹出以后，61H、62H 单元里的数据其实还在，只是 SP 不再指向它们，下次压栈会被覆盖。
- `10:03` 记住课件的示意图：PUSH 压入时，SP 先加 1 后压入；POP 弹出时，先弹出，SP 后减 1。

## [10:14–11:48] 使用栈操作指令注意（课件 P33）

- `10:15` 使用栈操作指令要注意六点。
- `10:18` 第一，PUSH、POP 的操作遵循先进后出的原则。
- `10:22` 第二，PUSH、POP 常成对使用，要注意顺序。
- `10:26` 比如刚才的例子，如果写成先 POP DPH、再 POP DPL，DPH 会拿到 56H，DPL 会拿到 80H，DPTR 变成 5680H，就恢复不了原来的 8056H。
- `10:44` 第三和第四，就是刚才的口诀：PUSH 先加 1 后压入，POP 先弹出后减 1。
- `10:52` 第五，课件写的是：SP 指针总是指在栈底，栈向上，也就是向地址增大的方向生成。
- `11:01` 这里要说明一下：从刚才的过程看，SP 始终指向最后压入的那个数据，也就是栈顶；60H 那一端才是栈底。
- `11:14` 所以课件这句的“栈底”和它自己的示意图不一致，我们以“SP 指向栈顶”为准。
- `11:21` 调用子程序指令和中断系统也会用到堆栈，所以要合适地设置堆栈大小，防止溢出。
- `11:30` 第六，PUSH、POP 的操作数只能是直接地址 direct，包括 SFR。
- `11:37` 所以写 PUSH DPH、PUSH DPL，而不能写 PUSH DPTR；补充一点，压入累加器时要写成 PUSH ACC。

## [11:48–13:31] 3. 交换指令 XCH、XCHD、SWAP（课件 P34、P35）

- `11:48` 第三类，交换指令，有两类：全字节交换指令 XCH，低半字节交换指令 XCHD。
- `11:58` 例 1：MOV A,#30H，MOV R0,#05H，A 等于 30H，R0 等于 05H。
- `12:08` 执行 XCH A,R0，两个字节整个互换：A 变成 05H，R0 变成 30H。
- `12:17` 例 2：MOV A,#12H，MOV R1,#50H，MOV 50H,#34H。A 等于 12H，R1 等于 50H，50H 单元是 34H。
- `12:32` 执行 XCHD A,@R1，只交换低 4 位：A 的低半字节 2，和 50H 单元的低半字节 4 对调。
- `12:41` 结果 A 等于 14H，50H 单元等于 32H，两边的高半字节都没动。
- `12:49` 注意：交换指令也称累加器 A 传送指令，目的操作数只能是 A，源操作数可以是 Rn、direct、@Ri 和 SFR。
- `13:01` 补充：这是对 XCH 而言的，XCHD 的源操作数只能是 @Ri。
- `13:07` 接着是 SWAP，高低四位互换指令。操作数只有一个，而且必须是 A。
- `13:15` 已知 A 等于 11000011B，也就是 C3H。
- `13:20` 执行 SWAP A，高 4 位 1100 和低 4 位 0011 互换，A 变成 00111100B，也就是 3CH。

## [13:31–15:09] 4. 程序存储器传送指令 MOVC：查平方表（课件 P36、P37）

- `13:32` 第四类，程序存储器传送指令 MOVC，只有两条。

## [15:09–16:09] 5. 片外 RAM 传送指令 MOVX（课件 P38、P39）

- `15:10` 第五类，片外数据存储器 RAM 传送指令 MOVX，共 4 条。

- `15:49` 4 条 MOVX 里，另一端都是 A：片外 RAM 的数据都要经过累加器 A 来传送。

## [00:00–01:05] 3.4 逻辑运算：三部分与四种法则（课件 P42、P43、P44）

- `00:12` 先复习四种逻辑运算法则。
- `00:15` 与运算，也叫逻辑乘，记作 Z 等于 A 乘 B，或者 A 与 B。只有输入信号都为 1 时，输出才为 1。
- `00:27` 或运算，也叫逻辑加，记作 Z 等于 A 加 B，或者 A 或 B。输入信号中有一个 1，输出就为 1。
- `00:38` 异或运算，记作 A 异或 B。输入信号相同则输出 0，输入信号相异则输出 1。

## [01:05–02:25] 3.4.1 对 A 的逻辑操作：CPL、CLR 与移位（课件 P45、P46）

- `01:06` 3.4.1，对累加器 A 进行的逻辑操作。CPL A，A 按位求反；CLR A，A 清 0。
- `01:15` 课件这里没给数据，我们用一个演示数据：A 等于 0E2H 时，CPL A 得到 1DH，每一位都翻过来；CLR A 以后，A 等于 00H。
- `01:30` 移位指令有四条，都是循环移位。
- `01:34` RR A：A 循环右移一位，每一位往右挪，最低位 D0 绕回到最高位 D7。
- `01:41` RRC A：带进位的循环右移，A 和进位 C 一共 9 位一起转：D0 移入 C，原来的 C 移入 D7。
- `01:52` RL A：A 循环左移一位，最高位 D7 绕回到最低位 D0。
- `01:58` RLC A：带进位的循环左移：D7 移入 C，原来的 C 移入 D0。
- `02:05` 助记符这样记：第一个字母 R，表示循环 Recycle；第二个字母表示方向，L 向左，R 向右；
- `02:15` 第三个字母如果是 C，表示连同 C 共 9 位一起移位；没有第三个字母，就和 C 无关。

- `02:26` 看课件的例子，注意每一步 A 和 C 的变化。

- `00:19` PSW 从最高位到最低位依次是：CY 进位位，AC 半进位位，F0 用户标志，RS1 和 RS0 工作寄存器选择位，OV 溢出位，
- `00:34` PSW.1 在课件里画成一横，没有定义；最低位是 P 奇偶位。
- `00:40` 先看高位进位标志 CY，简称 C：它反映算术运算时，最高位 D7 向更高位有没有进位或借位。
- `00:51` 有进位或借位，CY 等于 1；没有，CY 等于 0。

## [00:57–02:58] 半进位 AC 与溢出的概念（课件 P56、P57）

- `00:58` 半进位标志 AC：反映低半字节向高半字节，也就是 D3 向 D4，有没有进位或借位。有则 AC 等于 1，没有则 AC 等于 0。
- `01:13` 例：10101101 加 10101000。低 4 位 1101 加 1000 超过了 15，D3 向 D4 有进位，AC 等于 1；
- `01:25` 最高位也向外进位，CY 等于 1，8 位结果是 01010101。
- `01:32` 再看减法：10100101 减 00011000。低 4 位 0101 不够减 1000，D3 要向 D4 借位，AC 等于 1；整体够减，CY 等于 0，结果是 10001101。
- `01:50` 溢出标志 OV：反映运算结果是否发生溢出。有溢出 OV 等于 1，无溢出 OV 等于 0。
- `02:00` 什么是溢出？8 位有符号数的表示范围：原码和反码是负 127 到正 127，补码是负 128 到正 127。运算结果超过这个范围，就发生溢出。
- `02:17` 例：120 加 105 等于 225。01111000 加 01101001，得 11100001。
- `02:27` 两个正数相加，结果的符号位却是 1，成了负数，显然错误：225 已经超出了正 127。
- `02:38` 我们把 D6 向 D7 的进位叫做 C6，把 D7 向更高位的进位叫做 C7。这个例子里 C7 等于 0，C6 等于 1，有溢出，OV 等于 1。
- `02:52` 这就是数值位的溢出侵犯了符号位，发生错误。

## [02:58–04:04] 溢出判断：三种编码的范围与补码圆环（课件 P58、P61）

- `02:59` 看课件的表格。原码从 1111 1111B 到 0111 1111B，表示负 127 到正 127，其中 00H 和 80H 都表示 0。
- `03:13` 反码从 1000 0000B 到 0111 1111B，也是负 127 到正 127，00H 和 FFH 都表示 0。
- `03:26` 补码从 1000 0000B 到 0111 1111B，表示负 128 到正 127，0 只有 00H 一种写法。有符号数的加减运算，都按补码进行。
- `03:41` 课件的补码圆环图很好理解：从 0 出发往一边走，是 1、2，一直到 127；往另一边走，是负 1、负 2，一直到负 128。
- `03:55` 127 再加 1，就绕到了负 128。结果“绕过了头”，这就是溢出。

## [04:04–05:34] 溢出规律：OV = C7 ⊕ C6（课件 P59、P60）

- `04:05` 又例：负 3 加负 2，等于负 5。
- `04:09` 负 3 的原码是 10000011，反码 11111100，补码 11111101；负 2 的补码是 11111110。
- `04:21` 两个补码相加：11111101 加 11111110，得 1 11111011。丢掉最高位的进位，11111011 正是负 5 的补码。
- `04:34` 这里 C7 等于 1，C6 等于 1，OV 等于 0，没有溢出，结果正确。
- `04:42` 总结溢出规律：C7、C6 都是 0，数值位和符号位都没有溢出，OV 等于 0；
- `04:51` C7 为 0、C6 为 1，数值位溢出侵犯符号位，OV 等于 1；
- `04:58` C7 为 1、C6 为 0，符号位有溢出，OV 等于 1；
- `05:04` C7、C6 都是 1，虽然都有进位，但结果正确，OV 等于 0。
- `05:12` 一句话：C7 和 C6 相同，OV 为 0；相异，OV 为 1，这正好符合异或运算法则：OV 等于 C7 异或 C6。
- `05:23` 还要注意溢出 OV 和进位 CY 的区别：CY 主要用于无符号数的运算，OV 主要用于有符号数的运算。

## [05:34–06:17] 奇偶标志 P、RS1/RS0 与 F0（课件 P62）

- `05:35` 奇偶标志位 P：反映累加器 A 中 1 的个数是奇数还是偶数。偶数个 1，P 等于 0；奇数个 1，P 等于 1。
- `05:46` 比如等一下加法例子里的 40H，二进制 01000000，只有 1 个 1，P 等于 1；35H 是 00110101，有 4 个 1，P 等于 0。
- `05:59` 工作寄存器区选择位 RS1、RS0：前面讲过，改变它们的组合，可以切换 Rn 的不同工作区。
- `06:09` 用户标志 F0：可以由用户根据实际需要，规定它的意义。

## [06:17–08:26] 3.5.1 加法指令 ADD、ADDC 与标志变化（课件 P63）

- `06:18` 3.5.1 加法类指令。ADD A，第二操作数：A 加第二操作数，结果送 A。
- `06:26` ADDC A，第二操作数：A 加第二操作数，再加上进位 C，结果送 A。
- `06:35` 这两条指令影响 PSW 中的 CY、AC、OV 和 P 四个标志位。
- `06:42` 例：MOV A,#05H，然后 ADD A,#3BH。00000101 加 00111011，等于 01000000，A 等于 40H。
- `06:56` 看标志：最高位没有向外进位，C 等于 0；低 4 位 0101 加 1011 满 16，有半进位，AC 等于 1；
- `07:06` D6 没有向 D7 进位，C6 等于 0，C7 也是 0，OV 等于 0；40H 只有 1 个 1，P 等于 1。
- `07:17` 接着 ADD A,#0F5H：01000000 加 11110101，等于 1 00110101，A 等于 35H。
- `07:28` 最高位有进位，C 等于 1；低 4 位 0000 加 0101 没有半进位，AC 等于 0；C6 等于 1、C7 等于 1，OV 等于 0；35H 有 4 个 1，P 等于 0。
- `07:46` 最后 ADDC A,#70H：先算 35H 加 70H 得 A5H，再加上 C 的 1，得 A6H，也就是 10100110。
- `07:59` 最高位没有进位，C 等于 0；AC 等于 0；C6 等于 1、C7 等于 0，OV 等于 1；A6H 有 4 个 1，P 等于 0。
- `08:13` OV 等于 1 说明：如果把它们当有符号数，53 加 112 再加 1 等于 166，超过了 127，结果溢出。

## [08:26–09:27] 自增 1 指令 INC（课件 P64）

- `08:27` 自增 1 指令 INC：把指定单元的内容加 1，结果还放在原单元。比如 INC A，A 加 1 送 A；INC R0，R0 加 1 送 R0。
- `08:42` 注意：INC 指令不影响 PSW 中的标志位。
- `08:46` 所以课件说，分别运行 INC A 和 ADD A,#01H，A 的内容都加 1，但运行后 PSW 的内容不同。
- `08:58` 举个演示数据：A 等于 FFH。INC A 以后 A 变成 00H，CY 保持原来的值；ADD A,#01H 以后 A 也是 00H，但 CY 和 AC 都变成 1。
- `09:14` 补充一点：P 位总是跟随 A 的内容，所以 INC A 以后 P 也会更新；INC 不影响的，是 CY、AC、OV 这些运算标志。

## [09:27–11:18] 3.5.2 减法指令 SUBB 与 DEC（课件 P65、P66）

- `09:28` 3.5.2 减法类指令。SUBB A，第二操作数，是带借位减法：A 减第二操作数，再减 C，结果送 A。
- `09:39` 它同样影响 PSW 中的 CY、AC、OV 和 P 标志位。
- `09:46` 例：SETB C，C 等于 1；MOV A,#73H；然后 SUBB A,#86H。
- `09:54` 先算 01110011 减 10000110：不够减，要向更高位借 1，得 11101101；再减去 C 的 1，得 11101100，A 等于 ECH。
- `10:10` 标志：有借位，CY 等于 1；低 4 位 0011 不够减 0110，AC 等于 1；OV 等于 1；ECH 有 5 个 1，P 等于 1。
- `10:23` OV 为什么是 1？按有符号数看，73H 是正 115，86H 是负 122，115 减负 122 再减 1，等于 236，超出了 127。
- `10:41` 注意：减法指令没有不带借位的形式。用 SUBB 前要注意 C 的内容，如果不需要减 C，就先用 CLR C 把 C 清零，再做 SUBB。
- `10:55` ADD、ADDC、SUBB 指令中，一个加数或被减数一定要先存入 A，结果也在 A 里。
- `11:02` 自减 1 指令 DEC：指定单元内容减 1，结果在原单元，比如 DEC A，A 减 1 送 A。DEC 同样不影响 PSW 中的标志位。

## [11:18–13:20] 加减法综合举例（课件 P67、P68）

- `11:18` 来看一个加减法综合例子，结果依次存进 50H 开始的单元。
- `11:24` MOV R0,#50H，R0 指向 50H；MOV A,#55H，A 等于 55H。
- `11:34` ADD A,#7FH：55H 加 7FH 等于 D4H，没有向更高位进位，C 等于 0。MOV @R0,A，50H 单元等于 D4H。
- `11:49` INC R0，R0 等于 51H。ADD A,#70H：D4H 加 70H 等于 144H，A 留下 44H，C 等于 1。MOV @R0,A，51H 单元等于 44H。
- `12:06` INC R0，R0 等于 52H。ADDC A,#22H：44H 加 22H 等于 66H，再加上 C 的 1，A 等于 67H，C 等于 0。52H 单元等于 67H。
- `12:24` INC R0，R0 等于 53H。SUBB A,#89H：C 现在是 0，67H 减 89H 不够减，借位后得 DEH，C 等于 1。53H 单元等于 DEH，然后 R0 等于 54H。
- `12:44` SUBB A,#0AFH：DEH 减 AFH 得 2FH，再减去 C 的 1，得 2EH，没有借位，C 等于 0。54H 单元等于 2EH。
- `12:58` 注意 INC R0 和 MOV @R0,A 都不影响 C，所以 ADDC 和 SUBB 用到的 C，都是前一条加减法指令留下来的。
- `13:09` 最终 50H 到 54H 依次是 D4H、44H、67H、DEH、2EH，和课件结果一致。

## [13:20–15:53] 3.5.3 十进制加法调整 DA A（课件 P69、P70、P71）

- `13:21` 3.5.3，十进制加法调整指令 DA A，用于 BCD 码相加以后，对结果进行十进制调整。
- `13:31` 为什么要调整？例：96 加 89，应该等于 185。
- `13:38` 用 BCD 码按二进制相加：10010110 加 10001001，得 1 00011111。低 4 位是 1111，根本不是十进制数字，结果不对。
- `13:53` 调整的原则：以半字节，也就是 4 位为单位，过 9 就加 6 或 60H。
- `14:01` 具体说：AC 等于 1 时，低半字节加 6；CY 等于 1 时，高半字节加 60H；AC、CY 都是 1 时，加 66H。
- `14:13` 这个例子：低半字节 1111 大于 9，要加 6；CY 等于 1，高半字节要加 60H，合起来加 66H。
- `14:24` 00011111 加 01100110 等于 10000101，A 等于 85H，CY 仍为 1，合起来就是 BCD 码的 185。
- `14:38` 再看例 2：19 加 58 等于 77。MOV A,#19H，ADD A,#58H，二进制相加得 01110001，即 71H。
- `14:51` 低半字节 9 加 8 向高位有进位，AC 等于 1，所以 DA A 给低半字节加 6，得 01110111，即 77H。MOV 50H,A，50H 单元存放 BCD 码 77。
- `15:09` 使用注意：第一，DA A 只能用在加法指令之后，对减法指令的结果不能调整。
- `15:17` 第二，它是根据 A 的原始值和 PSW 的状态，对 A 进行加 06H、60H 或 66H 的操作。
- `15:26` 第三，参与相加的两个数必须都是组合 BCD 码，也叫压缩 BCD 码，调整后得到正确的 BCD 码结果；它不是把任意二进制或十六进制的加法结果变成十进制。
- `15:43` 第四，两个压缩 BCD 码按二进制相加之后，必须经过 DA A 调整，才能得到压缩 BCD 码的和。

## [15:53–17:14] 3.5.4 乘法指令 MUL AB（课件 P72、P73）

- `15:54` 3.5.4，乘法指令 MUL AB。51 系列只有无符号数的乘除法。
- `16:03` 它把 A 和 B 两个寄存器中的无符号 8 位二进制数相乘，积为 16 位：低 8 位放在 A，高 8 位放在 B。
- `16:14` 如果积不超过 8 位，也就是 B 的内容为 0，OV 等于 0，否则 OV 等于 1。乘法以后 CY 总是 0，AC 不变。
- `16:26` 例：16 乘 9 等于 144。MOV A,#10H，MOV B,#09H，MUL AB。
- `16:37` 144 等于 90H，没有超过 8 位：A 等于 90H，B 等于 00H，OV 等于 0，CY 等于 0，AC 不变。
- `16:50` 又例：80 乘 160 等于 12800。MOV A,#50H，MOV B,#0A0H，MUL AB。
- `17:00` 12800 等于 3200H：低 8 位 00H 放 A，高 8 位 32H 放 B。B 不为 0，所以 OV 等于 1，CY 等于 0。

## [17:14–18:15] 3.5.5 除法指令 DIV AB（课件 P73、P74）

- `17:14` 3.5.5，除法指令 DIV AB。A、B 中都是无符号整数，A 除以 B：商的整数部分存于 A，余数存于 B。
- `17:26` 运行后 CY 等于 0。如果除数 B 为 0，是非法操作，商为不定值，并且 OV 等于 1；B 不为 0 时，OV 等于 0。
- `17:40` 例：251 除以 18，等于 13 余 17。MOV A,#251，也就是 FBH；MOV B,#18，也就是 12H。
- `17:54` 执行 DIV AB：A 等于 0DH，也就是 13；B 等于 11H，也就是 17；OV 等于 0，CY 等于 0。

## [00:00–01:55] 3.6 控制转移：调用与返回（课件 P75、P76）

- `00:00` 第 5 集讲 3.6 控制转移指令，分四部分：无条件转移、条件转移、其它指令，以及综合举例。
- `00:10` 控制转移指令可以让程序转向非顺序的单元执行，使程序产生分支或循环。
- `00:19` 3.6.1 无条件转移指令。先看调用与返回指令。
- `00:24` 绝对调用指令 ACALL addr11：调用子程序。它只改变程序计数器 PC 的低 11 位，所以所调子程序的首地址必须在 2K 页内。
- `00:37` 补充更精确的说法：PC 的高 5 位保持不变，所以子程序必须和 ACALL 下一条指令的地址处在同一个 2KB 页内。
- `00:49` 长调用指令 LCALL addr16：所调子程序的首地址，可以在 64K 地址空间的任何位置。
- `00:58` 从子程序返回指令 RET：子程序执行完，用 RET 回到调用指令的下一条指令继续执行。
- `01:09` 它是怎么回得去的？我们用一组演示数据看看：假设 SP 等于 60H，地址 1000H 处有一条 LCALL 3000H。
- `01:21` LCALL 是 3 字节指令，返回地址是 1003H。调用时，单片机自动把 1003H 压栈：低字节 03H 进 61H，高字节 10H 进 62H，SP 变成 62H，然后 PC 变成 3000H。
- `01:41` 子程序最后执行 RET：从栈里弹出 10H 和 03H，PC 恢复成 1003H，SP 回到 60H，程序就回到了调用处。

## [01:55–03:38] 无条件跳转 AJMP、LJMP、SJMP 与偏移量（课件 P77、P78）

- `01:56` 无条件跳转指令有三条。绝对跳转 AJMP addr11：可使程序在 2K 页内跳转，也就是只改变低 11 位地址。
- `02:07` 长跳转 LJMP addr16：可使程序跳转到 64K 程序存储器的任何位置。
- `02:16` 相对短跳转 SJMP rel：rel 是偏移量，可以向上或向下跳转，范围是负 128 到正 127。
- `02:28` 差为负值，表示从大地址向小地址跳；为正值，表示从小地址向大地址跳。实际编程中很少直接给出地址，通常使用标号。
- `02:40` 看例子：MAIN 标号在 8000H；8006H 处是一条 SJMP，目标可以是 MAIN，也可以是 DIR；DIR 标号在 800FH。
- `02:54` 偏移量的计算公式：e 等于目的地址减去 PC 当前值，用补码表示。
- `03:02` PC 当前值，是跳转指令下面一条指令的地址。SJMP 占 2 字节，所以 PC 当前值是 8008H。
- `03:12` 跳到 MAIN 时：8000H 减 8008H 等于负 8，负 8 的补码是 F8H。
- `03:19` 跳到 DIR 时：800FH 减 8008H 等于 7，就是 07H。
- `03:27` 汇编器会自动算出偏移量，但考试常要求手算。记住一句话：目的地址，减去下一条指令的地址。

## [03:38–05:01] 间接转移 JMP @A+DPTR 与转移表（课件 P79、P80）

- `03:39` 间接转移指令 JMP @A+DPTR：把 A 和 DPTR 的内容相加，送入 PC。
- `03:48` 这是一条极其有用的多分支选择转移指令：由 DPTR 决定多分支转移程序的首地址，由 A 的内容动态选择其中的某一条分支。
- `04:00` 这样，一条间接转移指令就代替了众多的转移指令。
- `04:06` 课件的例子：设 A 中为 0、2、4、6 中的一个。MOV DPTR,#JMP-TBL，把转移表的起始地址送 DPTR；
- `04:19` JMP @A+DPTR，程序转向 A 加 DPTR 为地址的单元。
- `04:25` 转移表里依次放着 4 条 AJMP 指令：AJMP LABEL0、AJMP LABEL1、AJMP LABEL2、AJMP LABEL3。
- `04:34` 为什么 A 只取 0、2、4、6？因为每条 AJMP 是 2 字节指令，第 n 条在表首加 2n 处。
- `04:43` 比如 A 等于 4，就转到表首加 4，执行 AJMP LABEL2，最终到达 LABEL2。
- `04:51` 补充一点：多数汇编器不允许标号里出现减号，实际编程时可以写成 JMP_TBL。

## [05:01–05:49] 转移类指令注意事项（课件 P81）

- `05:02` 转移类指令要注意三点。第一，调用与返回指令常成对使用，返回指令 RET 应出现在每一个子程序的末尾。
- `05:13` 第二，调用与返回指令都要进行栈操作，使用这类指令前要建立堆栈，以便保护断点。
- `05:22` 第三，转移指令与调用子程序指令的异同。相同点：都改变 PC 的值，使程序转入非顺序单元执行。
- `05:32` 不同点：调用指令在子程序执行结束后，一定返回原断点地址，因此一定有栈操作；
- `05:41` 转移指令跳转以后不一定回到原断点，因此不需要用堆栈保存断点地址。

## [05:49–06:58] 3.6.2 条件转移：JZ、JNZ（课件 P82）

- `05:50` 3.6.2 条件转移指令：符合某种条件时，程序转移到另一地址执行；不符合时，程序按原顺序继续执行。
- `06:01` 第一种，判零相对转移指令：以累加器 A 的内容是否为 0 作为转移条件。
- `06:08` JZ rel：A 的内容为 0 则转移，否则顺序执行。JNZ rel：A 的内容非 0 则转移，否则顺序执行。
- `06:20` rel 偏移量和前面类似，是 8 位的，程序中可以写直接地址，也可以写标号地址。
- `06:29` 课件例子：MOV A,#56H，SUBB A,R0，JZ next：当减法结果为 0 时跳到 next 执行，否则继续往下执行。
- `06:41` 注意，课件没有给出 R0 和 C 的值。按 SUBB 的规则，只有 R0 加上 C 正好等于 56H 时，A 才为 0，程序才会跳转，比如 C 等于 0、R0 等于 56H。

## [06:58–08:44] 比较转移 CJNE（课件 P83、P84）

- `06:59` 第二种，比较相对转移指令 CJNE，它是三字节指令，格式是：CJNE 目的数，源数，rel。
- `07:09` 操作：把目的操作数和源操作数相比较，若不相等就相对转移，若相等就顺序执行。
- `07:19` 同时它会影响 C：若目的字节小于源字节，C 等于 1，否则 C 等于 0。指令执行后，两个操作数的内容都不改变。
- `07:31` 例：CJNE A,#04H,MAIN：A 不等于 04H 就跳转到 MAIN 标号，A 等于 04H 就顺序执行；如果 A 小于 04H，C 等于 1。
- `07:46` CJNE @R0,#05H,DIR：R0 所指单元的内容不等于 05H，就跳到 DIR 标号。
- `07:56` CJNE A,30H,STOP：A 不等于 30H 单元的内容，就跳到 STOP 标号。
- `08:04` 用演示数据看 CJNE A,#04H,MAIN：A 等于 02H，不相等，跳转，并且 02H 小于 04H，C 等于 1；
- `08:17` A 等于 04H，相等，顺序执行，C 等于 0；A 等于 09H，不相等，跳转，09H 不小于 04H，C 等于 0。
- `08:30` CJNE 指令一共有四种格式：A 和立即数比较，A 和直接地址单元比较，Rn 和立即数比较，@Ri 和立即数比较。

## [08:44–11:01] 循环转移 DJNZ 与软件延时（课件 P84、P85）

- `08:45` 第三种，循环转移指令 DJNZ，操作数，rel：操作数内容减 1，结果非 0 则转移，结果为 0 则顺序执行。
- `08:57` 第一操作数可以是 direct 或 Rn；该指令不影响任何标志位。
- `09:03` 例：DJNZ R0,LOOP，R0 减 1 结果非 0 就转到 LOOP 标号；DJNZ 30H,SQ，30H 单元减 1 结果非 0 就转到 SQ 标号。
- `09:17` DJNZ 最典型的用途是软件延时。例 1：MOV R1,#40，NEXT: DJNZ R1,NEXT，然后 RET。
- `09:29` MOV R1,#40 执行 1 次，占 1 个机器周期；DJNZ 执行 40 次，每次 2 个机器周期；RET 占 2 个机器周期。
- `09:42` 所以时间 t 等于 1 加 2 乘 40，再加 2，一共 83 个机器周期。
- `09:49` 例 2 是双重循环：外层 MOV R1,#50；内层 NEXT1: MOV R2,#40，NEXT2: DJNZ R2,NEXT2；外层 DJNZ R1,NEXT1；最后 RET。
- `10:07` 外层每转一圈：MOV R2 用 1 个周期，内层 DJNZ 用 2 乘 40 个周期，外层 DJNZ 用 2 个周期，一共 83 个周期，要转 50 圈。
- `10:22` 课件的公式：t 等于 1 加上，括号 1 加 2 乘 40 加 2，乘以 50，再加 2，算出来是 4153 个机器周期。
- `10:34` 补充：标准 51 单片机一个机器周期是 12 个时钟周期，如果晶振是 12MHz，一个机器周期是 1 微秒，例 2 大约延时 4.153 毫秒。
- `10:49` 课件写“指令周期见附录”，附录不在这份 PDF 里；这里用到的周期数，课件已经标在每条指令旁边。

## [11:01–12:06] 位条件转移与其它指令 RETI、NOP（课件 P86）

- `11:02` 第四种，以位地址的内容为判断条件的转移指令，一共五条。
- `11:07` JC rel：C 等于 1 跳转，C 等于 0 顺序向下执行；JNC rel：C 等于 0 跳转，C 等于 1 顺序执行。
- `11:20` JB bit,rel：该位等于 1 跳转，等于 0 顺序执行；JNB bit,rel：该位等于 0 跳转，等于 1 顺序执行。
- `11:32` JBC bit,rel：该位等于 1 就跳转，并且把该位清 0；该位等于 0 则顺序执行。
- `11:41` 3.6.3 其它指令。RETI：从中断返回指令，在中断系统中再详细介绍。
- `11:49` NOP：空操作指令。执行它时 CPU 不做任何操作，只是占用一个机器周期的时间。
- `11:58` 课件这页有两处“顺序问下执行”，应为“顺序向下执行”，是笔误。

## [12:06–13:45] 3.6.4 综合举例 1：判断 P1 的正负（课件 P87）

- `12:07` 3.6.4 控制转移指令综合举例。例 1：判断 P1 口输入的数据，若为负，转到 FS，否则转到 ZS。
- `12:18` 先看机器码：8000H 的 E5 90 是 MOV A,P1，90H 就是 P1 口的地址；8002H 的 33 是 RLC A；
- `12:30` 8003H 的 40、e1 是 JC FS；8005H 的 80、e2 是 SJMP ZS；FS 在 800AH。
- `12:42` 思路：有符号数的最高位是符号位。RLC A 把最高位移进 C，C 等于 1 就是负数，JC FS 跳走；否则 SJMP ZS，回去重新读 P1。
- `12:57` 求偏移量：e 等于目的地址减下条指令的地址，再取补码。
- `13:03` JC FS 的下一条指令在 8005H，FS 在 800AH：e1 等于 800AH 减 8005H，等于 05H。
- `13:15` SJMP ZS 的下一条指令在 8007H，ZS 在 8000H：e2 等于 8000H 减 8007H，等于负 7，补码是 F9H。
- `13:28` 用演示数据跑一遍：如果 P1 是 85H，最高位是 1，RLC 后 C 等于 1，JC 跳到 FS；如果 P1 是 35H，C 等于 0，SJMP 回到 ZS 继续读。

## [13:45–15:25] 综合举例 2：统计 20H 中 1 的个数（课件 P88）

- `13:46` 例 2：判断 20H 单元内容中 1 的个数。
- `13:50` MOV A,20H，把数取到 A；MOV R1,#08H，计数，判断 8 次；MOV R0,#00H，1 的个数计数单元清 0。
- `14:03` LOOP: RLC A，把最高位移进 C。JNC ZERO：C 等于 0 就跳到 ZERO；C 等于 1 就顺序执行 INC R0，计数加 1。
- `14:17` ZERO: DJNZ R1,LOOP：8 次没做完就回到 LOOP；做完 8 次，执行 STOP: SJMP STOP，暂停。
- `14:26` 课件没有给 20H 的数据，我们用演示数据：20H 单元等于 0B5H，也就是 10110101，跑一遍。
- `14:37` 每次 RLC 移进 C 的依次是 1、0、1、1、0、1、0、1；遇到 1，R0 就加 1。8 轮以后，R1 减到 0，R0 等于 05H，正好是 5 个 1。
- `14:52` 顺便说一句：RLC 会把原来的 C 移进 A 的最低位，但 8 次只移出原来的 8 位，所以 C 的初值不影响统计结果。
- `15:03` STOP: SJMP STOP 是一条跳回自己的指令，偏移量是 FEH；单片机没有真正的“停止”，常用这种死循环表示程序结束。
- `15:16` 控制转移指令就讲到这里。下一集讲汇编语言、伪指令，并做全章复习。

# 第 6 集 · 汇编语言、伪指令与复习

## [00:00–01:04] 3.7 汇编语言结构、指令与伪指令、ORG（课件 P89、P90）

- `00:00` 第 6 集讲 3.7 汇编语言和伪指令，最后做全章复习。
- `00:06` 3.7.1 汇编语言的结构。例如 LOOP: ADD A,30H，注释写的是：A 加上 30H 单元的内容，送 A。
- `00:17` 它由四部分组成：标号 LOOP，操作码 ADD，操作数 A 和 30H，以及分号后面的注释。
- `00:26` 3.7.2 伪指令。先分清两个概念：指令能够汇编成目标代码，能被计算机识别和执行；
- `00:37` 伪指令是用来控制汇编过程的，它不产生目标代码，也不能被计算机执行。
- `00:45` 第一条伪指令 ORG，起点指令，后面常跟一个双字节数据。
- `00:51` 它规定该指令后面的程序或数据块的起始地址。例如 ORG 8100H，后面的第一条指令就从 8100H 开始存放。

## [01:04–02:27] DB 定义字节与 MOVC 取数（课件 P91）

- `01:05` 第二条，DB，定义字节。
- `01:08` 例：ORG 2100H，FIRST: DB 01,32,83。数据可以写成二进制、十进制或十六进制。
- `01:19` ORG 指定这个数据块从 2100H 开始存放，所以标号 FIRST 代表 2100H；DB 把 01、32、83 依次存进 2100H、2101H、2102H。
- `01:36` 补充一点：这里的 32 和 83 没有后缀，是十进制数，存进去的十六进制分别是 20H 和 53H。
- `01:47` 也可以分三行写：DB 01，DB 32，DB 83，效果一样。
- `01:54` 要取出定义好的数据，就要用前面讲的 MOVC 指令：MOV DPTR,#FIRST，MOV A,#NN，MOVC A,@A+DPTR。
- `02:08` NN 等于 0，取出 01；NN 等于 1，取出 32；NN 等于 2，取出 83。
- `02:19` 课件这一页把同一个标号写成了 FIRST、FITST 和 FIRST1 三种样子，应是笔误，我们统一按 FIRST 理解。

## [02:27–03:37] DW 定义字与 DS 预留空单元（课件 P92）

- `02:28` 第三条，DW，定义 16 位数据，每个数据占两个字节。
- `02:34` 例：ORG 8000H，DW 7603H,7589H。
- `02:42` 结果是：8000H 单元为 76H，8001H 为 03H，8002H 为 75H，8003H 为 89H。
- `02:53` 可以看到，DW 把高字节存在低地址，低字节存在高地址。
- `02:59` 第四条，DS，定义若干空单元。例：ORG 5000H，DS 07H，后面跟着 MOV A,#7AH 和 ADD A,#22H。
- `03:14` DS 07H 从 5000H 开始预留 7 个空单元，也就是 5000H 到 5006H，以备后用。
- `03:23` 所以下面的 MOV A,#7AH 从 5007H 开始存放。补充：这条指令占 2 字节，所以 ADD A,#22H 从 5009H 开始。

## [03:37–05:35] EQU 赋值伪指令（课件 P93、P94）

- `03:38` 第五条，EQU，赋值指令，用于给标号赋值。
- `03:43` 例：MAA EQU 30H，则 MAA 与 30H 等价。所以 MOV MAA,#44H 和 MOV 30H,#44H 功能相同。
- `03:55` 再看课件的第二个例子：已知 30H 单元的内容是 50H。
- `04:01` MOV A,#MAA：有井号，MAA 当立即数用，A 等于 30H。
- `04:09` MOV A,MAA：没有井号，MAA 当直接地址用，A 等于 30H 单元的内容 50H。
- `04:17` LJMP MAA：课件注释写的是 PC 等于 50H，这一处有误。
- `04:24` LJMP 的操作数就是转移目标地址本身，MAA 等于 30H，所以执行后 PC 等于 0030H，而不是 30H 单元里的 50H。
- `04:37` EQU 的主要功能，是给一个表达式或字符串命名，相当于变量赋值。EQU 只能给标号赋值一次，整个程序中不能再更改。
- `04:50` 再如：LOOP EQU 8300H，LOOP 就代表地址 8300H。要往 8300H 单元写入数据 50H：MOV A,#50H，MOV DPTR,#LOOP，MOVX @DPTR,A。
- `05:08` 注意 8 位地址和 16 位地址的区别：16 位地址要放进 DPTR 间接访问，这时 16 位地址就相当于一个标号。
- `05:19` 课件还说，EQU 也可以用等号来代替，功能相同。这一点取决于所用的汇编软件，我们没能核实所有汇编器都支持，使用前请查所用汇编器的手册。

## [05:35–07:09] DATA/XDATA、BIT、END 与 DL（课件 P94、P95）

- `05:36` 第六条，DATA 和 XDATA，主要功能是给 RAM 单元命名：DATA 针对内部 RAM，XDATA 针对外部 RAM，和 EQU 功能类似，了解即可。
- `05:50` 例：JIEGUO DATA 50H，KAI XDATA 2040H。
- `05:56` 第七条，BIT，为位地址单元起名，类似 EQU，不同的是它定义的是一个二进制位。
- `06:04` 例：XIAO BIT 20H，给位地址 20H 起名 XIAO；CG BIT PSW.5，给 PSW 的第 5 位，也就是用户标志 F0，起名 CG。
- `06:18` 第八条，END，汇编语言程序结束标志。汇编时遇到 END，它后面的程序和数据都不再生成目标代码。
- `06:27` 第九条，DL，定义标号值：COUNT1 DL 2300H，定义 COUNT1 等于 2300H；COUNT2 DL COUNT1+1，定义 COUNT2 等于 2301H。
- `06:42` 和 EQU 不同，DL 可以在同一源程序中，对同一标号多次赋值。
- `06:49` 需要说明：在常见的 Intel ASM51 和 Keil A51 汇编器里，我们没有找到 DL 这种写法；Keil A51 中允许重复赋值的伪指令是 SET。请以你们课程所用的汇编软件为准。

## [07:09–08:41] 复习要点与全章总结（课件 P96）

- `07:10` 最后是课件的复习要点，我们逐条回顾。
- `07:14` 第一，寻址方式：一共七种。重点记住寄存器间接、变址和相对寻址，分别访问哪个存储空间。
- `07:25` 第二，111 条指令：按功能分为数据传送、算术运算、逻辑运算、控制转移和位操作。
- `07:35` 第三，堆栈：PUSH 先加 1 后压入，POP 先弹出后减 1，SP 指向栈顶；子程序调用和中断都要用到堆栈。
- `07:46` 第四，累加器 A：大多数运算和传送都离不开 A，MOVC、MOVX、XCH 和 DA 的操作数都必须是 A。
- `07:56` 第五，访问存储器的指令：片内 RAM 用 MOV，片外 RAM 用 MOVX，程序存储器 ROM 用 MOVC。
- `08:06` 第六，指令写法是否正确：比如 PUSH DPTR、MOV 24H.1,1、MOV A,@R2，以及以字母开头的十六进制数不加 0，这些都是错误写法。
- `08:21` 第七，常用伪指令：ORG、DB、DW、DS、EQU、DATA、BIT 和 END。
