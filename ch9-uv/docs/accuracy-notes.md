## 2. 课件没有给出、由视频补充的内容

**示意图形**（画面均标注“示意”）
- 各类谱图都是为比较位置和强弱而画的示意曲线，不是实测数据：吸收光谱曲线，R、K、B、E 带曲线，苯和乙酰苯的光谱。
- 血红素和叶绿素的卟啉环是简化结构。

**其他**
- “能量越大，吸收波长越短”：由 P16 的能量顺序图和 P8 的能量—波长表推出。
- 读数 “A = 0.575”：沿用 P5 示意图中的数值，仅作演示。

## 3. 配音说明

- **合成方式**：配音由开源离线语音模型合成（Matcha-TTS，Baker 中文语料）。
- **自动校对**：用离线中文语音识别（Paraformer）逐句转写回文本，与讲稿按拼音比对。平均差异约 3%，剩下的主要是识别器把同音字写错（如“跃迁”写成“月签”），不是读音错误。
- **字母的读法**：这个模型只会读中文，所以配音里把字母按教师常用的读法念出：R → 阿尔，K → 开，B → 必，E → 伊，d → 迪，f → 艾弗，max → 最大值。字幕和画面保留规范符号。
- **建议**：仍建议教师在正式使用前完整听一遍。
